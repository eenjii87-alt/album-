# Гэр бүлийн цомог

Гэр бүлийн зургаа жинхэнэ цомог шиг хадгалж, аав ээжтэйгээ хуваалцаж, хамт олондоо зургийг эх чанараар нь дамжуулах сайт.

**Сайт:** https://family-album.petal-store-mongolia.workers.dev

| Хаяг | Юу вэ | Хэн орох вэ |
|---|---|---|
| `/` | Гэр бүлийн цомог: модон ширээн дээрх ном шиг хуудас, стикер, бичиг, зурах, он сараар, хана, PDF хэвлэх, сэтгэгдэл | Эзэн, «Гэр бүл» |
| `/share/` | Хамт олны зураг дамжуулах: эх чанараар, ZIP-ээр татах | Эзэн, «Хамт олон» |
| `/admin` | Хэн нэвтрэх, Google Sheets холболт, хадгалах зай | Зөвхөн эзэн |
| `/login` | Имэйлээр ирсэн 6 оронтой кодоор нэвтрэх | Бүх зөвшөөрөгдсөн хүн |

## Хэрхэн ажилладаг вэ

```
Хөтөч ──► Cloudflare Worker (src/worker.js)
             ├─ D1 «family-album»         цомог, хуудас, сэтгэгдэл, хэрэглэгч, нэвтрэлт
             ├─ KV «family-album-photos»  зургийн файлууд (1 ГБ хүртэл үнэгүй)
             ├─ GitHub (энэ репо)         public/ доторх хуудсуудыг татаж үзүүлнэ
             └─ Google Apps Script        Gmail-ээр нэвтрэх код илгээж, Google Sheets-д бүртгэнэ
```

- `public/` доторх файлыг GitHub дээр өөрчилбөл сайт **1–5 минутын дотор** өөрөө шинэчлэгдэнэ.
- `src/worker.js`-ийг өөрчилбөл Cloudflare руу дахин байршуулах хэрэгтэй: `npx wrangler deploy` (эсвэл Claude-оор).
- `public/album.html`, `public/share.html` нь Claude дээр хийсэн хуудаснууд. `public/shim.js` тэдгээрийг энэ Worker-ийн өгөгдлийн сантай холбоно.

## Google Sheets ба Gmail-ийг нэг удаа холбох

1. https://sheets.new дээр шинэ хүснэгт нээнэ.
2. **Extensions → Apps Script**. `apps-script/Code.gs`-ийн кодыг хуулж тавина. Хамгийн амархан нь сайтын `/admin` хуудаснаас «Кодыг хуулах» товчоор хуулах, тэнд таны түлхүүр аль хэдийн орсон байна.
3. `setup` функцийг **Run** хийж Google-ийн зөвшөөрөл өгнө.
4. **Deploy → New deployment → Web app**. Execute as: **Me**, Who has access: **Anyone**.
5. Гарсан `…/exec` хаягийг `/admin` хуудсанд тавьж «Холбох» дарна.

Үүний дараа Sheets-д «Цомог», «Зураг», «Сэтгэгдэл», «Илгээмж» гэсэн хуудсууд гарч, мөр бүр автоматаар бичигдэнэ.

## Хязгаар (Cloudflare-ийн үнэгүй багц)

- Зураг: нийт 1 ГБ, нэг файл 20 МБ хүртэл, өдөрт 1000 удаа хадгалах.
- Нэвтрэх код: Gmail өдөрт ойролцоогоор 100 имэйл илгээнэ.
- Цомгийн зургийг 2048 цэг хүртэл жижигрүүлж хадгалдаг. Зураг дамжуулах хуудас эх файлыг хадгална.

## Аюулгүй байдал

- Нэвтрэх код 10 минут хүчинтэй, 5 удаа буруу оруулбал хүчингүй болно. Нэвтрэлт 60 хоног хадгалагдана.
- «Зөвхөн би» цомгийг эзнээс өөр хэн ч уншиж чадахгүй.
- Хувийн мэдээлэл (имэйлүүд, зураг) энэ репод байхгүй, Cloudflare дээр хадгалагдана.
